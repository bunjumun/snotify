Applied to the picture before the effect reads it, not after: displacement is driven by pixel value, so this changes how far a line pushes, not just how the picture looks.
Output size
The canvas takes the image's own proportions at this size. Spacing, width and strength scale with it, so raising this makes a finer drawing of the same picture — which is what a plotter wants.
Displacement
A bigger step reads fewer pixels along each line: coarser, and much faster on a large output.
